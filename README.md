# Power BI Project 1 — SuperStore Orders

## Project Overview
This project uses Microsoft Power BI to analyze SuperStore order data and explore sales, profit, quantity, customer segments, product categories, and regional performance.

## Objectives
- Clean and transform data using Power Query.
- Analyze sales and profit performance.
- Create interactive KPI cards, charts, slicers, and filters.
- Display detailed order information in a separate report page.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- GitHub

## Dataset
The dataset contains order dates, shipping information, customer details, product categories, sales, quantity, discount, profit, and region.

## Data Preparation
- Renamed columns for readability.
- Checked and adjusted data types.
- Checked null values in Sales and Profit.
- Filtered customer segments to Consumer and Corporate.
- Split Order ID using a hyphen delimiter.
- Removed unnecessary columns where applicable.

## Dashboard Features
- KPI cards for key metrics.
- Sales by Category.
- Profit by Region.
- Sub-category sales analysis.
- Region and Category slicers.
- Interactive filters and cross-filtering.
- Order Details table on a separate page.

2. Order Details
